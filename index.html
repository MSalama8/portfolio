I’m a student at the Faculty of Computers and Information, Zagazig University, discovering how data can help explain real-world problems. Right now, I’m strengthening the fundamentals: writing SQL queries, understanding data quality, and using Python tools to explore datasets.

I don’t present myself as an expert. My goal is to show the process honestly: ask a clear question, inspect the data, build a reproducible solution, and explain what the result means. Every project is a chance to practice that process and make my work easier for others to review.

This portfolio is my public learning log — a place for finished work, experiments, and the next questions I’m working on.
